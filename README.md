# Iron Saint

FPS Studio **Iron Saint**, Iteration **I-17**. Engine: **Godot 4.3**. Second arena dress beat.

## Clone / open

```
git clone -b iter/I-17 https://github.com/zachmofo/fps-studio.git
cd fps-studio
```

Godot **4.3** → open `project.godot` → **F5**.

1. Capture, then fight. Same CoverMid / dummy peek lane. Sparks on hit (I-16). Heavy rifle tip left of + (I-15).
2. North wall: sealed door panel + rust frame behind the dummy lane (visual only).
3. Ceiling: 3 cold-mint cage lights (unlit boxes, no Omni).
4. Floor: dark stains near crates + grate. Mid-wall scuff bands on north + east.
5. I-14 grate / far-left pillar / right-wall pipes kept. Return-fire + CLEARED unchanged.
6. **WASD** walk 5.0. **Shift** sprint 8.0. **Space** jump. **Esc** frees the cursor.

Sounds live under `res://audio/`.
