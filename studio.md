\f0\fs24 \cf0 # FPS Studio\
\
Human owner: Zach. Reed reports to Zach. Everyone else reports to Reed.\
\
## Product\
Working title: TBD (Reed proposes 3 names in kickoff).\
Genre: first-person shooter.\
v0 goal: a playable vertical slice, not a boxed game.\
Must have in v0:\
- Mouse look + WASD\
- Sprint, jump\
- Hitscan or projectile weapon with muzzle, recoil, ammo\
- One enemy type that can damage and be killed\
- Player health + death/respawn\
- One arena with cover\
- Win condition (clear the room) and lose condition (death)\
- On-screen HUD: health, ammo, objective\
Out of scope until Zach unlocks it: multiplayer, campaign, crafting, vehicles, store pages, paid ads.\
\
## Loop\
1. Vega ships a playable build + changelog on a branch.\
2. Pike and Wren independently test that exact build.\
3. Both testers file reports to Reed only (not to Vega).\
4. Reed triages, does design + code review, writes one prioritized ticket list.\
5. Vega implements the next slice. Repeat.\
\
## Definition of done (every iteration)\
- Runnable instructions in README\
- Changelog of what changed\
- Known issues list from Vega\
- Two tester reports attached or linked\
- Reed signed the iteration (pass / pass-with-fixes / fail)\
\
## Approval wall (never skip)\
Needs Zach:\
- Merge to main\
- Public links, store listings, domain publish\
- Spending money\
- Changing the v0 goal or adding a major system\
- Deleting the repo or rewriting the engine mid-slice\
\
Allowed without Zach:\
- Feature branches\
- Local / preview builds\
- Bug reports, design notes, code review comments\
- Reed creating tickets\
\
## Voice\
Short. Evidence over vibes. No \'93looks good\'94 without a repro, a clip, a log, or a file path.}
